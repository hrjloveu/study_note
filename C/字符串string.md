### 定义字符串
字符串实际是由许多单字符组成的数组
```c
char t[] = "Hello World";
printf("%s", t);
```
==定义字符串用双引号，格式说明符为`%s`==

>输出：
>Hello World

实际上，字符串就是一个末位元素为`'\0'`的数组
```c
char t[] = {'a', 'b', 'c', '\0'};
```

### 字符串常量
通过指针的写法，可以定义一个只读的字符串常量
```c
char *t = "HellloWorld";
```
该字符串实际储存在系统的代码段里，指针指向了这个代码段，如果试图更改该字符串可能会造成严重后果


---
### 字符串的输入与输出

空格、换行、制表符被视为终止字符，这意味着它只能读取输入的一个单词
```c
char t[10];  
char u[10];  
scanf("%s", t);  
scanf("%s", u);  
printf("%s\n", t);  
printf("%s\n", u);
```
>输入： Hello World
>
>输出：  
>Hello  
>World  


当需要限制用户输入字符串的长度，可以使用安全输入
```c
scanf("%5s", t);
```
此时，只会读取用户输入的前5个字符

### 字符串数组

如果需要定义一个包含多个字符串的数组，可以使用类似二维数组的写法
```c
char *t[] = {"abc", "123", "def", };
```
这种写法是什么意思？实际上我们定义了一个数组，这个数组内包含了多个指针，每个指针都可以指向不同的字符串

### 字符串函数
首先需要导入c语言的标准库`string.h`

 ```c
 #include <string.h>
 ```

###### strlen

返回字符串长度，不算末尾的'\0'
```c
char t[] = "abc";
printf("%d",strlen(t));
//3
```

###### strcmp

比较两个字符串是否相同，若相同返回0，若不相同，返回非0数值
```c
char a[] = "abc";  
char b[] = "abc";  
printf("%u", strcmp(a, b));
//0
```


###### strcpy

复制后面字符串的内容到前面的字符串

```c
char a[4];  
char b[4] = "abc";  
strcpy(a, b);  
printf("%s\n", a);
//abc
```
