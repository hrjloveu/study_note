### 基本数据类型

|   数据类型   | 内存大小 |         描述          |    例子     |   格式说明符   |
| :------: | ---- | :-----------------: | :-------: | :-------: |
|  `int`   | 4字节  | 整数，-32,768 ~ 32,767 |   `520`   | `%d`或`%i` |
| `float`  | 4字节  |    单精度浮点数，6-7位小数    |  `13.14`  |   `%f`    |
| `double` | 8字节  |    双精度浮点数，15位小数     |  `13.14`  |   `%lf`   |
|  `char`  | 1字节  |    字符，实际是ASCII值     | `'Hello'` |   `%c`    |

格式说明符`%i`能自动识别进制，输出八进制、十进制、十六进制的整数

---
### 扩展数据类型

| 数据类型                     | 内存大小  | 范围                       | 格式说明符  |
| ------------------------ | ----- | ------------------------ | ------ |
| `unsigned (int)`         | 2或4字节 | 0 ~ 65535                | `%u`   |
| `long int`               | 4字节   | -2147483648 ~ 2147483647 | `%ld`  |
| `long long int`          | 8字节   | 很大                       | `%lld` |
| `unsigned long int`      | 4或8字节 | 很大                       | `%lu`  |
| `unsigned long long int` | 8字节   | 很大                       | `%llu` |

---

### 强制数据类型转换
```c
// 手动转换：int 到 float
float sum = (float) 5 / 2;
printf("%f", sum); // 2.500000
```
一个变量声明后不可以改变数据类型

### 科学计数法

我们在c中使用科学计数法表示数据需要使用以下格式

`num+e+幂`

例如：
```c
printf("%f",0.3e5)
// 0.3e5 = 0.3*10^5 = 30000

printf("%f",0.3e-5)
// 0.3e-5 = 0.3*10^-5 = 30000
```
