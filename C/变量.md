### 定义变量

一个变量使用前需要定义
```c
int num = 520;
char text = 'Hello';
double data = 9.1;
```
可以同时定义多个同类型变量
```c
int a = 1, b = 2, c = 3;
```

需要注意的是，变量定义在块（大括号）内，生存期和作用域都在块内，在块外定义的变量可以在块内使用，但是如果这个变量在块内被修改，不会同时修改块外该变量的值

### 常量

定义常量，定义后不可更改

```c
const int NUM = 1314;
#define PI 3.14
```

定义常量时我们习惯使用大写字母命名

同时，`const`还可用于数组



---
### 全局变量

定义在函数外的变量是全局变量

任何函数都能够调用并修改它

但是，不建议把全局变量和另一个全局变量关联在一起

在函数内部声明的变量是本地变量，当出现和全局变量同名的本地变量，全局变量会被暂时隐藏

---
### 静态本地变量


静态本地变量的初始化只会在第一次进入这个函数时做，当函数离开的时候，静态本地变量会继续存在并保持其值

在本地变量定义时加上static修饰符就成为静态本地变量

```c
static int num = 1;
```

静态本地变量，有全局变量的生存期，但是有本地变量的作用域

---

### 全局变量声明

变量的声明与定义是两个完全不同的东西

跨文件的全局变量需要声明后才能正常调用

```c
extern int gALL
```
这相当于告诉编译器在整个项目的某个地方有这样一个全局变量

全局变量声明通常被写在头文件里
