头文件里包含了各种函数的声明

在一个c代码的开头我们都会写上`#include`，实际上这是把一个内置的名为`stdio.h`的文件原封不动的复制到你的代码里，

我们也可以使用`#include`引入自己的文件，例如

- main.c
```c
#include <stdio.h>
#include "max.c"
int main(void)
{
	printf("%d\n", max(10, 20));
	return 0;
}
```
- max.c
```c
int max(int a, int b)
{
    if (a > b)
        return a;
    else
        return b;
}
```

这时，我们将max.c中的代码原封不动地导入进了`main.c`中`#include "max.c"`的那一行


注意，如果使用`<>`让编译器从指定目录寻找文件；使用`""`让编译器从当前源代码文件目录寻找文件，如果找不到再去指定目录寻找


如果在全局变量或函数前加上`static`，代表它只能在当前`.c`文件中使用

### 标准头文件结构

一个变量不能被重复定义，但是可以重复声明

但是，当我们有多个头文件，我们有时候不可避免的定义多次变量或结构体等，这时候我们需要一个类似与if判断的写法，防止多次定义

```c
#ifndef _MAX_H_
#define _MAX_H_

#include <max.h>
int i = 0;

#endif
```

这里的`_MAX_H_`类似于宏
