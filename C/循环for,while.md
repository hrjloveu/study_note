### for循环
```c
//循环10次
for (int i = 0; i < 10; i++) { //初始值; 循环条件; 每次循环执行的代码
	printf("%d\n", i);//循环内容
}
//初始i=0，最终i=10
```
`int i = 0`在代码块执行之前执行一次

`i < 10`定义了执行代码块的条件

`i++`在代码块执行后执行（每次循环后）

---

### while循环
先做判断再循环
```c
while (循环条件) {
	//循环内容
};

```

---

### do while循环
先循环一边再判断
```c
do {
	//循环内容
} while (循环条件);
```

---

### 循环语法
```c
break//跳出整个循环
continue//跳过这轮循环剩下的语句，直接进入下一轮循环
```

---

### 三种循怎么选？

有固定次数用for，必须执行一次用dowhile，其他情况用while
