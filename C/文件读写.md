### 读取文件

我们需要创建一个指针，指向我们需要打开的文件

以后需要对文件操作时需要调用整个指针

打开文件的标准代码：

```c
#include <stdio.h>
int main(void)
{
    FILE *fp = fopen("input.txt", "r"); //r是打开文件的mode
    if (fp) //如果文件存在
    {
        int num;
        fscanf(fp, "%d", &num); //读取文件内容
        printf("The number is: %d\n", num);
        fclose(fp); //关闭文件
    }
    else //如果文件不存在
    {
        printf("Failed to open file.\n");
    }
    return 0;
}
```


文件打开mode如下

`r`只读

`r+`读写，从文件头开始

`w`只写入，如果不存在则新建，如果存在则清空

`w+`读写，如果不存在则新建，如果存在则清空，可以读到刚写入的内容

`a`打开追加，如果不存在则新建，如果存在则从文件尾开始

