### 不返回值的函数
```c
#include <stdio.h>  
void sum(int a, int b) {  
    printf("%d", a + b);  
    return; //return;可有可无
}  
int main() {  
    sum(3, 4);  
    return 0;  
}
```
`void`函数中可以写`return;`但不能写返回值

### 返回值的函数
定义函数时需要写返回值的数据类型
```c
#include <stdio.h>  
int sum(int a, int b) {  
    return a + b;
    printf("函数被调用")//此代码在函数被调用的时候也会执行
}  
int main() {  
    printf("%d", sum(3, 4));  
    return 0;  
}
```
返回值的函数每次被调用也会执行一次函数内代码

定义该函数时，头部的`int`为返回值的数据类型，当然，我们可以用各种数据类型作返回值，包括结构体变量、数组等

### 原型声明

当需要把函数定义写在main函数之后时，需要进行原型声明。告诉编译器函数参数和返回值的数据类型。
```c
#include <stdio.h>  
int sum(int a, int b);//亦可写为 int sum(int, int);  
int main() {  
    printf("%d", sum(3, 4));  
    return 0;  
}  
int sum(int a, int b) {  
    return a + b + 1;  
}
```
如果函数没有参数或返回值，原型声明时需要写`void def(void);`
