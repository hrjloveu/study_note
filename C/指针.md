
---

指针就是保存地址的变量  
另外，函数参数里的数组就是指针，即数组变量是特殊的指针

---

### 获取内存大小
```c
int Int;
float Float;
double Double;
char Char;

printf("%lu\n", sizeof(Int)); //4
printf("%lu\n", sizeof(Float)); //4
printf("%lu\n", sizeof(Double)); //8
printf("%lu\n", sizeof(Char)); //1
```

---

### 定义指针变量
```c
int num = 8;
int *p = &num;//名为p的指针，指向变量num
```


`&+变量名`就是一个变量的地址，需要把该地址定义给指针

此时，`*p`是一个指针，指向`num`变量的地址


---


### 调用指针
指针变量是十六进制数字，格式说明符为`%p`
`*`作用是创建指针，或获取指针指向的变量
指针在创建后`*p`与`num`是等价的
```c
printf("%p",p); //输出指针指向变量的地址
printf("%d",*p); //输出指针指向的变量

*p = 6; //改变指针指向变量的值，不受函数限制
```

当需要在函数内改变某变量的值：
```c
#include <stdio.h>  
void plus(int *p, int);  
int main(void) {  
    int a = 5;  
    int *ap = &a;  
    plus(ap, 3);  
    printf("%d", a);  
    return 0;  
}  
void plus(int *p, int num) {  
    *p += num;  
}
```

### 指针运算

指针运算指的是改变指针的值，使其指向内存中的不同元素

数组元素在内存中是相邻存储的，因此，如果一个指针指向一个元素，加1就会使其移动到下一个元素

```c
int a[] = {1, 2, 3, 4,};
int *p = a;

printf("%d\n", *p); 
printf("%d\n", *(p + 1)); 
printf("%d\n", *(p + 2));
printf("%d\n", *(p + 3));
```
>输出：  
>1  
>2  
>3  
>4  

当给指针加 1 时，它向前移动的距离是其指向类型的大小，而不仅仅是1个字节
- 一个 `int*` 指针移动的距离是一个整数的大小，4 字节
- 一个 `char*` 指针移动的距离是一个字符的大小，1 字节


减去两个指向同一数组中元素的指针，可以找出它们之间相隔多少个元素

```c
int a[5] = {1, 2, 3, 4, 5,};
int *start = &a[1]; //指向2
int *end = &a[4];   //指向5
printf("%d\n", end - start); //相隔3个元素
```

>输出：  
>3

### 常量指针

当指针时const，指针p不能再指向其他变量
```c
int *const p = &i;
```

当所指是const，不能通过指针p修改原变量
```c
const int *p = &i;
int const *p = &i;
```


因为数组也是指针，所以可以定义一个const数组，该数组里面的元素不可修改
 ```c
 const int a[] = {1,2,3,4,5,};
 ```

### 指针类型

如果不关心指针指向的是什么类型的变量，可以使用void类型指针

```c
void *p = &a;
```

指针类型可以转换

```c
int a = 1;  
void *p = &a;

int *q = (int*) p;
printf("%d\n", *q);
```
>输出：  
>1
