### 定义数组

`类型 数组名称[元素数量];`

或使用数组的集成初始化 `类型 数组名称[] = {num1, num2, num3, };`

```c
int list[3]; //定义一个元素数量为3的数组
list[0] = 1; //给第0位的元素赋值

printf("%d", list[0]); //输出：1
```

我们使用数组时需要注意一下事项：

1. 数组内所有元素是同一种数据类型

2. 数组大小一旦创建就无法更改

3. 数组超限不会报错，但是程序是危险的

4. 数组之间不能比较是否相等，即`a = b`是错误的

### 数组大小

求数组内元素个数

`数组元素个数 = 数组的总大小 / 一个元素的大小`

```c
int list[] = {10, 25, 50, 75, 100};
int len = sizeof(list) / sizeof(list[0]);

printf("%d", len);  //输出 5
```

### 二维数组

定义二维数组
```c
int l[3][5];
```
这是一个3行5列的数组，共有15个元素

注意，定义二维数组时，==不能省略列数，即后一个放括号内的数字==

### 数组与指针

数组的名称实际上是指向数组第一个元素的指针

```c
int list[10];
int *p = list//无需加“&”
```
此时，指针`p`指向该数组，地址为`&list[0]`

即`p == &list[0]`成立

并且，数组可以直接把实参传入函数

但是数组中的元素是变量，而不是指针
```c
int *q = &list[5] //此时需要加“&”
```
