### 编译预处理
在c语言中，编译前会先进行编译预处理，#是编译预处理符号

### 定义宏
`#define 名字 值`
使用宏能实现语句的替换，例如
```c
#include <stdio.h>
#define PI "3.14159"
int main(void)
{
    printf(PI);
    return 0;
}
```
>输出： 
>3.14159

定义宏时添加的`//`注释不会作为值替换

如果需要给一个宏定义多行值，可以使用`\`表示定义没有结束，例如：

```c
#include <stdio.h>
#define PRT      \
    printf("a"); \
    printf("b"); \
    printf("c");
int main(void)
{
    PRT;
    return 0;
}
```

### 预定义的宏

C语言中内置了很多预定义的宏，这些宏可以拿来直接用，例如

`__LINE__`源代码行号

`__FILE__`源代码文件名，包含全路径

`__DATE__`编译时的日期

`__TIME__`编译时的时间

### 带参数的宏

`#difine 宏名称(参数) 表达式f(x)`

定义一个带参数的宏，例如

```c
#include <stdio.h>
#define plus(x, y) ((x) + (y))
int main(void)
{
	printf("%d\n", plus(1, 2));
	return 0;
}
```
>输出： 
>3


定义宏时不需要加分号

我们在定义宏的时候要注意，整个值要有括号，一切参数都要有括号，这样才能避免其他运算符号优先级对宏的影响
